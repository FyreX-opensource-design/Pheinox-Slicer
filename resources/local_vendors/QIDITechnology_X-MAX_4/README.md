# QIDI X-MAX 4 local vendor pack

Import this pack into preFlight via **Configuration Wizard → Load local vendor bundle (ZIP)**.

## Contents

- Printer model **X-MAX 4** (390×390×340 mm), nozzles 0.2 / 0.4 / 0.6 / 0.8
- Klipper / Moonraker G-code flavor matching other QIDITechnology profiles
- Bed mesh / start macros modeled on X-Plus 4 (`PRINT_START`)

## Import steps

1. Open preFlight → Configuration Wizard (or Preferences → Configuration Wizard)
2. Click **Load local vendor bundle** and select `QIDITechnology_X-MAX_4.zip`
3. Enable **QIDITechnology (local)** / **X-MAX 4** and finish the wizard
4. Select printer preset `X-MAX 4 0.4 nozzle` (or your nozzle size)

Bed STL/SVG are adapted from the X-MAX 3 assets scaled to 390 mm — replace with official assets when available.

This is a **local** pack only; it is not published to profiles.preflight3d.com.
